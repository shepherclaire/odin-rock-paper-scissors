# odin-rock-paper-scissors
Odin Project - JavaScript project "Rock-Paper-Scissors" in Foundations course

Make a rock paper scissors games using javascript

Program will prompt the user to enter a choice (rock paper or scissors) and will compare it against a randomly selected choice by the computer to determine a winner of the round 

The program plays 5 rounds total, then reports an overall game winner

Program does not handle reprompting if the user enters an invalid input
